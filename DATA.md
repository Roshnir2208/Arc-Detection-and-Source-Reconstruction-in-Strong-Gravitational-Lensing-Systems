# Data Policy

This repository intentionally does not include the full datasets used during development and evaluation.

## Included

Small demonstration assets are included in `examples/`, including:

- representative synthetic lens images,
- corresponding ground-truth arc masks,
- corresponding ground-truth source images,
- final 64 x 64 reconstructed source images,
- metadata for selected synthetic samples, and
- one real SLACS/HST demonstration image with associated detection and reconstruction outputs.

These files are included to support quick testing and live demonstration of the pipeline.

Final evaluation summaries and representative result figures are also included in `results_summary/`.

## Not Included

The following are excluded because they are large, generated, or externally sourced:

- full 1,000-image synthetic Lenstronomy evaluation dataset,
- larger generated synthetic datasets,
- Galaxy Zoo source dataset,
- raw SLACS/HST FITS downloads,
- full reconstruction output folders,
- intermediate diagnostic figures,
- local caches, and
- model checkpoints.

## Synthetic Dataset Regeneration

Generate a small synthetic dataset using:

```powershell
python scripts/generate_synthetic_dataset.py --count 10 --out-dir data/lenstronomy_demo
```

Larger datasets can be generated by increasing `--count`. Large generated datasets should remain outside Git or under an ignored `data/` directory.

## Galaxy Zoo Data

Galaxy Zoo labelled source images were used for the quantitative morphology-classification experiments. The full dataset is not redistributed in this repository.

Users wishing to reproduce these experiments should obtain the required data from the original Galaxy Zoo/SDSS data sources and follow the corresponding licence and attribution requirements.

## Real Lens Data

Real lens demonstrations use selected SLACS/HST observations. Full raw FITS downloads are not redistributed in this repository.

The real-data experiments are treated as qualitative demonstrations rather than quantitative source-reconstruction validation because equivalent source-plane ground truth is unavailable.

## Evaluation Results

The full experimental datasets are not distributed, but final evaluation summaries are provided in `results_summary/`, including results for:

- gravitational arc detection,
- source reconstruction,
- morphology classification, and
- forward validation.

Configuration files corresponding to the final experimental settings are provided in `configs/`.
