# Experiments

This folder contains non-final or supporting experiment scripts retained only for dissertation reproducibility.

The final pipeline entry points are in `scripts/`.

Included experiment scripts support:

- reconstruction improvement ablations,
- sparse beta-plane coverage diagnosis,
- source-grid resolution ablation,
- mapping audit against exact Lenstronomy ray-shooting,
- COSMOS/Galaxy-Zoo style real-source benchmark experiments.

These scripts are not the recommended live-demo path and may require external datasets that are intentionally not included in this repository.
