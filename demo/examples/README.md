# Demo Examples

The release demo reads the small fixed examples stored in the repository-level `examples/` directory.

Included examples:

- `lens_00932_observed.png`: representative synthetic lensed image.
- `lens_00932_true_mask.png`: corresponding ground-truth arc mask for the synthetic image.
- `lens_00932_true_source.png`: corresponding true source image.
- `lens_00932_reconstructed_source64.png`: final 64 x 64 reconstructed source used for the quick demo.
- `J1023p4230_00_real_input.png`: real SLACS/HST demonstration image.
- `J1023p4230_00_real_detection.png`: final real-data detection output.
- `J1023p4230_00_real_reconstructed_source.png`: final real-data reconstructed source candidate.

The real-data example is qualitative only because source-plane ground truth is unavailable.
